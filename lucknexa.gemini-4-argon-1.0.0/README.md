## 💎 Overview & Architecture

Gemini 4 Argon bridges the gap between state-of-the-art foundation models and hands-on developer workspaces. Unlike simple chat assistants, Gemini 4 Argon operates as an **Autonomous Principal Engineer**:

- **Autonomous Tool Execution**: Surgically reads, writes, and edits files; runs test suites; executes terminal commands; and maps project structures.
- **Universal Multi-Model Adapter**: Access the flagship **Gemini 4 Argon** alongside Anthropic's latest **Claude Opus 5.5, 5, 4.8, 4.7** hosted natively on Google Cloud Vertex AI Model Garden.
- **100% Free Frontier Inference**: Uses standard Google Cloud Application Default Credentials (ADC) so all token consumption is billed directly against your **$300 (₹26,000 INR) Google Cloud Free Trial Credits**.
- **Model Context Protocol (MCP) Standard**: Connect seamlessly to Claude Desktop, Cursor, Codex, and remote AI clients via stdio and HTTP/SSE.
- **Glassmorphism Native UI**: Apple Ceramic Light & Deep Space Dark modes with instant live streaming, progress badges, and multi-turn session persistence.

## ☁️ How to Run Latest Claude Models for 100% FREE on Vertex AI (Via $300 Credits)

Anthropic is an official Google Cloud Model Garden partner. This means you can run the latest **Claude Opus 5.5, Claude Opus 5, Claude Opus 4.8, Claude Opus 4.7, and Claude Sonnet 5.5** using your **$300 (₹26,000 INR) Google Cloud Free Trial Credits** without paying Anthropic directly!

### Step-by-Step Setup:

#### Step 1: Enable Claude in Vertex AI Model Garden
1. Open the [Google Cloud Console](https://console.cloud.google.com/).
2. In the top search bar, type **Vertex AI Model Garden** and open it.
3. In the Model Garden search bar, type `Claude Opus` or `Anthropic`.
4. Click on the model card (e.g. **Claude Opus 5.5** or **Claude Opus 5**).
5. Click **"Enable"** or **"Get Started"** to activate the model for your Google Cloud project. Google grants immediate access for accounts with active billing or free trial credits.

#### Step 2: Authenticate Locally via Google Cloud ADC
Run once in your terminal:
```bash
gcloud auth application-default login
gcloud config set project YOUR_PROJECT_ID
```
*(Replace `YOUR_PROJECT_ID` with your Google Cloud Project ID).*

#### Step 3: Configure in Gemini 4 Argon
1. Open **Antigravity IDE** or **VS Code**.
2. Click the **⚙️ Settings** icon in the Gemini 4 Argon sidebar.
3. Set **AI Engine** to: **`Anthropic Claude (Vertex AI Model Garden)`**.
4. Select your desired model tier (e.g. **`Claude Opus 5.5`** or **`Claude Opus 5`**).
5. Leave the **Anthropic API Key** field blank — the extension will automatically authenticate via your Google Cloud ADC!
6. Click **Save Settings**.

**That's it!** All Claude requests route directly through Google Cloud Vertex AI and draw from your **$300 Free Trial balance**. You get world-class Claude Opus intelligence completely for free!

## ✨ Core Capabilities & Architecture

### 🛠️ Autonomous Workspace Tools (Model Context Protocol)

Gemini 4 Argon ships with a full suite of autonomous workspace tools adhering to the open **Model Context Protocol (MCP)** JSON-RPC standard:

| Tool Name | Autonomous Action & Safety Behavior |
| :--- | :--- |
| `read_file` | Line-number window slicing (`startLine` to `endLine`). Reads files up to 100,000+ lines without token overflow. |
| `write_file` | Creates or overwrites files. Auto-generates missing folders and creates `.argon_bak` backup. |
| `edit_file` | Surgical search-and-replace refactoring with CRLF/LF smart normalization and backup preservation. |
| `list_dir` | Explores directories and inspects folder sizes with recursive options. |
| `get_workspace_structure` | Maps recursive project trees while automatically ignoring `node_modules`, `.git`, `dist`, `__pycache__`. |
| `search_code` | Ultra-fast regex and symbol searching across the entire codebase. |
| `run_command` | Executes terminal commands (`pytest`, `npm test`, `cargo`, `git`) with a generous **5 MB output buffer**. |
| `gemini_4_argon_reason` | Direct deep reasoning consultation with Gemini 4 Argon inside Claude or Codex. |

Gemini 4 Argon v1.1.0 features native multimodal capability:

## 🛡️ Resilient Rate Limiting & Cooldown Engine

When executing heavy autonomous loops across hundreds of files, foundation models may encounter transient rate limits (`HTTP 429` / `RESOURCE_EXHAUSTED`):
- **Exponential Backoff**: Gemini 4 Argon automatically pauses execution and initiates a visual countdown timer directly in the UI.
- **Zero Loss of Context**: The entire multi-turn tool calling stack is safely retained in memory during the cooldown.
- **Automatic Continuation**: Once the timer elapses, execution resumes automatically without requiring user intervention.

## 🤝 Universal Compatibility: Claude Desktop, Cursor & Codex MCP

Gemini 4 Argon implements a complete **Model Context Protocol (MCP)** server, making its autonomous tools available to other frontier environments:

### Claude Desktop Integration (`claude_desktop_config.json`)
Add the following to your Claude Desktop config file:
```json
{
  "mcpServers": {
    "gemini-4-argon": {
      "command": "node",
      "args": [
        "PATH_TO_EXTENSION/mcp/server.js"
      ],
      "env": {
        "GEMINI_PROJECT_ID": "YOUR_GCP_PROJECT_ID",
        "GEMINI_LOCATION": "global",
        "GEMINI_AUTH_METHOD": "adc"
      }
    }
  }
}
```

### Cursor & Codex Integration
Add the Gemini 4 Argon MCP server in Cursor settings under **Features > MCP Servers** with the same `node mcp/server.js` command.

### Remote MCP HTTP/SSE Bridge (`start-mcp-server.bat`)
For environments requiring remote or HTTP-based MCP endpoints:
- Double click **`mcp/start-mcp-server.bat`** (or run `node mcp/http-server.js`).
- The server will start locally on port `3333` and optionally expose an encrypted Cloudflare HTTPS tunnel for remote access.

## 🔒 Zero-Data Privacy & Security

- **Direct Cloud Connection**: Requests travel directly between your machine and Google Cloud Vertex AI / Anthropic endpoints. No intermediary servers, third-party relays, or logging proxy layers exist.
- **Automatic `.argon_bak` Backups**: Every destructive file edit creates a timestamped safety backup in your workspace before writing changes.
